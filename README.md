# Haryana Resume & Application Generator

Free browser tools (no server, no sign-up).

- `index.html` – home page
- `resume-generator.html` – resume maker
- `application-generator.html` – application / letter / affidavit maker
- `pro-studio.html` – document crop, photo and ID card sheet maker

## Publish free with GitHub Pages
1. Create a new **public** repository on github.com.
2. Click **Add file → Upload files**, drag in every file from this folder (including `.nojekyll` if visible), then **Commit changes**.
3. Go to **Settings → Pages**. Under *Build and deployment*, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save.
4. After 1–2 minutes your site is live at `https://<your-username>.github.io/<repo-name>/`.

Cash settings

How cash is counted: paid entries received in Cash add cash. If you entered a Charge and the money came by Google Pay, PhonePe or another online mode, the shop pays out the Amount minus the Charge in cash. AEPS withdraw takes cash out. AEPS deposit and jail canteen transfers bring cash in. Expenses marked Cash go out. Pending entries count on the day they were entered. Anything else goes in Cash in / out. Each closing becomes the next day’s opening cash.

Colour theme

My colours (learn HTML / CSS)

Pick a colour and the whole app changes at once. In the app's CSS every colour is a variable such as --ink. Rules like body{color:var(--ink)} use it, so one change updates every screen. Your choice is saved in this browser and stays when you change the theme. Press Default to go back to the theme colour.

To see the real code: open this HTML file in Notepad and search for :root (the colour variables) and .btn{ (the buttons).

Use as a desktop app (Windows)

Get an icon for your taskbar. It opens in its own window with no address bar and no tabs, like a normal program.

  1. Press Create app icon. A small setup file downloads.
  2. Open that file. If Windows asks, choose Keep or Run anyway.
  3. The icon appears on your Desktop and in the Start menu. Right-click it and choose Pin to taskbar.

Use the same browser you normally open this file in. Each browser keeps its own data, so if the app window looks empty, use Restore below. If you move or rename this HTML file, create the icon again.

Chrome alternative: menu ⋮ → Save and share → Create shortcut, and tick “Open as window” (wording varies by version).

Backup your data

Your entries are saved in this browser on this computer. Download a backup regularly (it includes Aadhaar numbers, so keep the file safe). Last backup: never

Excel ledger (auto-fill)

Link your Shop_Ledger.xlsx once. After that every entry you save here is also written into its Entry sheet (new entries are added, edits and “Mark paid” update the same row, a deleted entry is removed). Works in Chrome / Edge. Keep the Excel file closed while you work; anything waiting is added the next time it is closed.

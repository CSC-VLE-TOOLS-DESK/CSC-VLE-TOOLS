CSC VLE TOOLS v29  (5 Nov 2026)

1. "This tool failed to load. Refresh the page." (AI Couple Photo etc.)
   That message appears only when the tool's script file did not load. It worked on every test here, so on your server
   the file is probably missing / not uploaded yet or an old copy is cached. What changed:
   - site.js now retries the download by itself (with a cache-buster). If a file is really missing, the page now says
     exactly which file: e.g. "These files were not found on the server: assets/js/tools-album.js. Upload the whole assets folder again."
   - All pages now load their scripts/styles as ...?v=28, so after you upload this version browsers cannot mix old and new files.
   >> When you upload to GitHub, upload the WHOLE "assets" folder (js, css, maps) and all .html files, not only some of them.
      New files this time: assets/js/borders.js, tools-album.js, tools-scan.js (from v27) and the 3 new ledger .html files.

2. NEW LEDGERS (each is one self-contained page, data saved in the browser, with Backup / Restore, CSV, Print and "Load sample data" to practise):
   - Medical Store Ledger  medical-store-ledger.html : medicines with BATCH NO and EXPIRY DATE, buying (purchase bills with free qty, discount, GST, freight),
     selling bills (earliest-expiry batch first, expired batch cannot be sold, cannot sell more than stock), expiry alerts (expired / 30 days / your chosen days),
     write-off / return of expired stock, transport & expenses, customers/suppliers dues + payments + statements, GST report (CGST/SGST/IGST by rate, input vs output, month-wise), profit, printable bill with drug licence no.
   - Book Shop Ledger  book-shop-ledger.html : same engine for books and stationery (publisher, class/subject, ISBN, trade discount on buying, GST 0/5/12/18/28 per item).
   - Insurance Ledger  insurance-ledger.html : policy register, renewal reminders (overdue + next N days) with one-tap WhatsApp message, premium collection with receipt print,
     next due date moves forward by itself, deposits to company (collected vs deposited vs pending), commission earned vs received, GST on commission, TDS note, transport/travel expenses, income report.
   Added to: Receipts & Billing (10 tools), Daily Use Apps on home, search, sitemap, and the right "New Tools" panel (now 9 tools).
   GST rates are typed per item (not fixed) because rates change; every screen says to confirm with your CA.
